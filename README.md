
## Privacidad

- El **audio** se procesa dentro de la propia aplicación con Whisper: no se
  envía a ningún servicio externo de transcripción.
- La **foto** del candidato/a es SOLO registro de expediente: nunca se envía a
  ningún modelo ni influye en el puntaje.
- Solo la **transcripción** (texto) viaja al LLM de HuggingFace para el análisis.

## Aviso de uso responsable

Este asistente es un APOYO a la decisión; la decisión final siempre es de una
persona. Los modelos de lenguaje pueden equivocarse: el informe declara
limitaciones y el reclutador debe verificar la evidencia citada contra la
transcripción antes de decidir.
